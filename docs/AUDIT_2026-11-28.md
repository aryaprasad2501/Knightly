# Knightly audit — what's built and how to check it (2026-11-28)

Build state: Flutter 3.50.1 · Riverpod 3.5 · database schema v16 ·
`flutter analyze` clean · 548 automated tests pass · debug APK builds.
Every stage since the `review-start-2026-11-28` tag is in REVIEW_LOG.md with its
commit.

How to use this: install the latest build on your phone and work down the
lists. **Bold** marks what only a real phone can confirm (the emulator couldn't).

## 1. App shell

- [ ] Dock: Home sits in the middle. Settings › Dock style offers:
  - Arc reactor
  - Crest
  - Capsule
  - "every 2 app starts"
  - "every 30 minutes"
- [ ] Swipe left/right between tabs.
- [ ] Back on any tab goes to Home; back on Home asks "Leave Knightly?".
- [ ] Home "+" floats: drag it anywhere, restart the app, and it stays there. Tap it for the add panel:
  - Mission, Event, Habit, Routine
  - Water, Food, Sleep, Workout
  - Home care job
- [ ] Themes: Dark Knight (blue) and Shadow Cat (rose). Each has its own pictures, fonts, sounds and dock look.

## 2. Home

- [ ] Briefing:
  - % done and commitments ring
  - 4 gauges visible; swipe for more, with dots and an arrow
  - no half-visible 5th gauge
- [ ] Tonight's mark (next mission), today's schedule, Home care card.

## 3. Missions (Tasks tab)

- [ ] Create, edit and delete; undo from the Recycle Bin.
- [ ] Dates, times, priority, projects.
- [ ] Repeats: daily, weekdays, weekly, monthly, **yearly**, custom.
- [ ] Checklist: add steps in the editor; the card shows "1/3"; ticking saves at once; the next repeat starts unticked.
- [ ] Search icon: matches title, notes, checklist and project, in open and done missions.

## 4. Habits & Routines (Track)

- [ ] Habits: check off today, and also past days this week (tap the day dots).
- [ ] Routines: run step by step with timers.

## 5. Calendar

- [ ] Day, week and month views; events, missions and habits together.
- [ ] Event editor: "Birthday · yearly" makes an all-day yearly event with a reminder that morning.

## 6. Trackers (Track tab)

- [ ] Water:
  - quick add
  - details page
  - tap a past day to add or delete drinks for that day
- [ ] Sleep: log nights; details page.
- [ ] Workouts:
  - start, log sets and finish
  - details page
  - **Save as template**, then Start workout offers the template, with sets pre-filled and unticked
- [ ] Nutrition: meals, foods and targets; details page.
- [ ] Home care:
  - jobs with schedules and custom categories
  - reminders
  - **"When I get home"** (needs location "Allow all the time")
- [ ] Track › arrange: drag modules into your own order.

## 7. Insights

- [ ] Score with the hexagon/rings; tilt the phone and it moves.
- [ ] Weekly review panel:
  - score change
  - strongest and weakest area
  - missions
  - streak
  - best day
- [ ] Links (need about 3+ days on each side):
  - sleep vs habits
  - workouts vs sleep
  - water vs habits

## 8. Reminders (Settings › Reminders)

- [ ] Timed missions, events, routines, water nudges, sleep wind-down, habits left.
- [ ] **Reminders arrive on a release build** (an icon bug that stopped them in release was fixed).

## 9. Places (Settings › Places)

- [ ] Set home here (also in Home care › Reminders).
- [ ] Add a place here (e.g. Office) with a reminder.
- [ ] **Arriving at home/office shows the notification**; never confirmed on the emulator.

## 10. Home-screen widgets

- [ ] **Long-press the home screen › Widgets › Knightly** shows 5 widgets:
  - Today
  - Missions
  - Habits
  - Water
  - Next event
- [ ] **Tapping a module widget opens that module.**
- [ ] Settings › Home-screen widget: choose the Today widget's two lines.

## 11. Settings

- [ ] Dock style, Sounds, Live backdrop, Low mode, Reduce motion.
- [ ] Modules: switch off what you don't use.
- [ ] Backup & restore:
  - export JSON
  - restore
  - safety copies
- [ ] Recycle Bin.
- [ ] About: "Made by Arya", version, small Licences link.

## 12. Account & cloud sync (optional)

- [ ] Settings shows "Continue with Google" at the top. **It is optional**: without signing in, everything works offline as before.
- [ ] **Sign in** with a Gmail that is a test user on the OAuth consent screen.
- [ ] Account & sync shows:
  - "Up to date"
  - "Last synced just now"
  - Sync now
- [ ] **Firebase console › Firestore › users › (your id)** has collections such as `tasks` and `habits`.
- [ ] **Reinstall test:**
  1. add a few missions, habits and water;
  2. wait for "Up to date";
  3. uninstall, reinstall, sign in.

  Everything comes back.
- [ ] **Second phone** (optional): the same account shows the same data; an edit on one appears on the other after Sync now.
- [ ] Offline: airplane mode, add something. The screen says "Waiting for internet"; turn data back on, tap Retry, and it goes up.
- [ ] First sign-in when both the phone and the account have data:
  - it asks: merge, use the account's copy, or use this phone's copy;
  - a safety copy appears in Backup & restore.
- [ ] Sign out: choose keep or remove this phone's data.
- [ ] Delete account: removes the cloud data and the account; the phone keeps its data unless you choose otherwise.

## 13. Under the hood (covered by automated tests)

- Database migrations v1→v16 (`test/drift`).
- Change tracking:
  - edits collapse
  - deletes leave markers
  - device-only settings are skipped
- Sync engine, two simulated phones and one cloud:
  - links kept
  - newer edit wins
  - deletions sync and can be revived by a later edit
  - no duplicate check-ins
  - offline queue
  - first-sign-in merge / cloud / phone
  - fresh-install restore
- Backups include checklists and workout templates.

Before a Play Store release:
- Confirm the final app ID (`com.knightly.app`).
- Create the release key (docs/RELEASE_SIGNING.md) and add its SHA-1/SHA-256 to Firebase (and Play's app-signing key).
- Privacy policy and the Data safety form (cloud sync now sends data off the phone, only when signed in).
- Move the OAuth consent screen from "Testing" to "In production".
- Trademark review of theme names and store text.
- Measure performance on a real low-end phone.

Theme pack: batches 2–4 (more icons, page visuals, animations) are not wired in.
