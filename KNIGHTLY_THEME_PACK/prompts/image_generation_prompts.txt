KNIGHTLY — IMAGE GENERATION PROMPTS (optional, photo-realistic versions)
=======================================================================

Batch 1 files were painted in code; these prompts let you re-create any of
them photo-realistically in an AI image tool you choose. Keep the asset
number in the file name so it drops into the right slot.

Rules for every prompt
- Portrait 1080×2400 (aspect 9:20), WebP or JPG, dark cinematic grade.
- Focal light upper-right; keep the top-left (page titles) and the middle
  column (cards) calm and dark.
- Never ask for trademarked names, logos or characters (no "Batman",
  "Catwoman", "Gotham", "DC", bat-in-oval logo). The bat/cat shapes must be
  generic silhouettes.
- Negative prompt for all: text, watermark, logo, signature, people's faces,
  recognisable characters, superhero costume, blur, lens dirt.
