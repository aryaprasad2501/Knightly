# Theme implementation

How the pack plugs into the Knightly app (Flutter, `lib/core/design/`).

## Where files go in the app

| Pack folder | App location | Notes |
|---|---|---|
| `*/wallpapers/` | `assets/themes/<theme>/wallpapers/` | One wallpaper per page world (see below) |
| `*/backgrounds/` | `assets/themes/<theme>/layers/` | Live overlay layers for `KLiveScene` |
| `*/textures/`, `shared/textures/` | `assets/themes/<theme>/textures/` | Panels, frames, grain |
| `*/branding/`, `shared/UI/` | `assets/brand/` | Emblems, crests, wordmarks |
| `*/launcher/` | `android/app/src/main/res/mipmap-*` | Generated by `tool/brand/` (one launcher icon, see ARCHITECTURE D29) |

Register each folder in `pubspec.yaml › flutter › assets`. Only approved files move into `assets/`.

## Theme to asset mapping

`KnightlyThemeId` gains a `KThemeAssets` record (paths only, no logic):

```dart
final class KThemeAssets {
  const KThemeAssets({required this.wallpapers, required this.layers, required this.emblem, ...});
  final Map<KPageWorld, String> wallpapers; // home, tasks, track, calendar, settings
  final KSceneLayerSet layers;              // beam, clouds, fog, particles, rain, glow, leaks
  final String emblem;                      // branding PNG
}
```

Suggested page worlds:

| Page | Dark Knight | Shadow Cat |
|---|---|---|
| Home | #12 city signal | #19 moonlit rooftop cat |
| Tasks | #16 street | #23 violet atmosphere |
| Track | #18 abstract tactical | #25 abstract stealth |
| Calendar | #17 dusk city | #20 purple moon |
| Settings | #14 command cave | #24 elegant rooftop |
| Alt / rain mode | #13, #15 | #21, #22 |

## Colour and contrast

Text is never placed directly on a wallpaper without a scrim: page content sits on panels
(`KSurface`) and the header region gets the scene's fade. Keep body text contrast ≥ 4.5:1 against
the panel colour, not the image.

## Textures on panels

Use textures at low strength, tiled, inside the panel shape:
- Dark Knight: carbon fibre (#81) or dark metal (#83) at 25–40 % under the panel gradient; HUD frame
  (#84) as a 9-slice decoration on highlighted panels only.
- Shadow Cat: black leather (#87) at 20–35 %; curved panel (#92) for hero cards; neon frame (#91)
  for one focal element per screen at most.
- Grain (#93) over the whole app at 3–5 %, painted once (not per card).
